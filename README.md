# Adventskalender für Mama – mit Mafalda

Ein Online-Adventskalender mit 24 Türchen: Mafalda-Sprüche (Spanisch im Original + deutsche Übersetzung), kleine „Mafalda-Momente“ als Gutscheine und eine persönliche Nachricht am 24.

## Nutzung
- `index.html` im Browser öffnen, fertig. Es ist eine einzige Datei ohne Abhängigkeiten.
- Türchen *n* lässt sich ab dem *n*. Dezember 2026 öffnen. Geöffnete Türchen werden im Browser gemerkt.
- **Vorschau zum Testen:** `index.html?vorschau` öffnet alle Türchen.

## Online stellen (damit Mama einen Link bekommt)
GitHub → Settings → Pages → Branch auswählen → Ordner `/ (root)`. Danach ist der Kalender unter `https://<benutzername>.github.io/<repo>/` erreichbar.

## Inhalte anpassen
Alle Texte stehen oben im `<script>` im Objekt `TUERCHEN`.

## Comics einbetten
Bei jedem Türchen kann ein Beitrag des **offiziellen** Instagram-Accounts [@mafaldadigital](https://www.instagram.com/mafaldadigital/) eingebettet werden:
`post: "https://www.instagram.com/p/XXXX/"`. Das Bild bleibt bei Instagram, es wird nichts kopiert.
Bitte **keine Screenshots oder Bilddateien** ins Repository legen – das wäre eine Urheberrechtsverletzung.
Die Einbettung funktioniert nur auf der echten Website (GitHub Pages), nicht bei einer lokal geöffneten Datei.
